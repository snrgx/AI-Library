# SNRGX AI Library

Infusing AI into process engineering: visual, bilingual (EN/AR) skills, plugins and MCP tools for founders and creators, with a friendly UI/UX, so anyone can use them.

Built by **SNRGX**. Every tool is checked for safety before release.

## Tools

| Tool | What it does | Status |
|---|---|---|
| 🛡️ [**Check Link**](plugins/check-link) | Paste any link and get a trust check before you install or open it. AI skills, plugins and MCP servers: score out of 10, risk matrix, OWASP Agentic Skills Top 10, red flags and a safe-install prompt. Websites, documents and short links: look-alike addresses, requests for passwords or cards, hidden AI instructions | [v1.6.0](plugins/check-link/CHANGELOG.md) |

More tools are on the way.

## Install the library (Claude Code)

```
/plugin marketplace add snrgx/AI-Library
/plugin install check-link@snrgx
```

Every new tool added here appears in the same library. Each tool's own README explains other ways to install it, including the Claude app.

## Safety

Every tool in this library is reviewed with **Check Link** before release. Found a problem? See [SECURITY.md](SECURITY.md).
