# Security policy

Check Link is a set of instructions (text only). It contains no scripts, hooks or MCP servers. It never installs, runs or downloads what it checks, and it never logs in, types into or submits anything on a page it reads.

## Reporting a problem

If you find a way the skill could be tricked (for example, a skill that fools it into a "low risk" verdict), or any other security issue:

- Open a [private security advisory](https://github.com/snrgx/AI-Library/security/advisories/new) on this repository, or
- Open an issue without sensitive details and we will follow up.

Please don't post working attack examples publicly before we've had a chance to fix them.

## Versions

Only the latest version is supported. Changes are listed in [CHANGELOG.md](CHANGELOG.md).
